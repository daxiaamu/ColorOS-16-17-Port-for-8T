## 版本来源

- 硬件：8T 原厂 ColorOS 14 内核、设备树和硬件相关分区，加上逐项验证的兼容处理。
- 早期供体：PKX110（一加 13T）ColorOS 16，用于初次启动与硬件探索。
- 当前供体：PMD110（OPPO Reno15c）16.0.10.501，保留其框架并迁移已验证的 8T 修复。
- r15 无 ROOT 预装基线：最新 system/system_ext/reserve 写入并读回验证；手动 Format Data 后首启、原生预装和正常重启通过。官方底包实测为 KB2000_13.1.0.186 F.73、DDR4、B 槽。
- 后续晕动舒缓候选 system/system_ext 已写入并读回验证，包含手动输入兼容、CMC 自动识别适配及原生设置模式修复；已纳入 20260911 完整包（内部构建 r19）。详见 [motion-relief](motion-relief.md)。
- 最新 20260911 完整包（内部 r19）已完成离线校验、NAS 交付及读回哈希验证；扫一扫与最终版本号候选镜像完成重启验证。该完整 ZIP 再次刷入和覆盖升级仍待验收。历史 r14 可开机但预装挂载失败，不能当作已修复产物。
- 安装策略为预先准备官方 OS13/14、保留全部底层固件、写入并启动当前槽、用户手动格式化。60 个可读取官方包汇总为 88 个去重固件指纹，匹配不等于每种底包/DDR 均已启动验证。
- PMD 主观流畅反馈不能证明“金标”或 CPU 拓扑是性能改善根因。
- **ColorOS 17：没有实机移植或验证证据。**
